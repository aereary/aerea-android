# Private shelf acceptance checks

- Open from the aérea brand in Your Library. With no PIN configured the catalog opens normally.
- Set an 8+ digit PIN in Settings. Close and reopen; incorrect PIN fails. Five failures require waiting one minute. Correct PIN opens; changing/removing requires current PIN.
- Leave app with PIN enabled, including while reading. Return requires PIN; other library screens remain available.
- Search a prefix, select a suggested tag, type another prefix, select another: results must contain BOTH tags on one work. Remove each chip individually. Existing type, status and fandom filters still apply.
- Download a real EPUB. Confirm success only after native storage returns. Downloaded shows it; Read uses the existing reader. Reopen app and verify persistence. Existing native AO3 downloads should appear after inventory refresh.
- University files remain in Your Library. AO3 files remain in app storage, visible under Downloaded. No file migration or deletion occurs.
- Choose App theme: existing cards and tags keep their layout. Test Midnight Rose / Sea Glass on phone and tablet. Test large system text.
- Verify AO3 source links, copies of titles, series expansion, alternatives, new badges, refresh, offline cached catalog, reader progress, bookmarks and Back navigation.
- PIN is a local UI access lock, not file encryption; backups and previously exported copies are not protected by this lock. Imported copies without native AO3 provenance are not moved or guessed from filenames.
